# 📌 Realtime Chat Application

A real-time chat application built using **React, Tailwind CSS, Zustand, and Socket.IO**. Users can join rooms and send messages instantly.

## 🚀 Features

✅ Realtime Messaging with Socket.IO  
✅ Join & Leave Chat Rooms  
✅ User Presence Indicator (Active users list)  
✅ Optimized UI with Tailwind CSS  
✅ State Management using Zustand  
✅ Emoji Support via `react-emoji`  
✅ Responsive & Mobile-Friendly

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Zustand, React Router, Lucide Icons
- **Backend:** Node.js, Express, Socket.IO
- **State Management:** Zustand
- **Icons:** Lucide React

## 📦 Installation

### 1️⃣ Clone the Repository

```sh
git clone https://github.com/your-username/realtime-chat-app.git
cd realtime-chat-app
```

### 2️⃣ Install Dependencies

```sh
npm install
```

### 4️⃣ Start the Development Server

```sh
npm run dev
```

Frontend will run at **`http://localhost:5173`** (if using Vite).

## 📡 Running the Backend

1. **Navigate to Backend Folder**
   ```sh
   cd backend
   ```
2. **Install Backend Dependencies**
   ```sh
   npm install
   ```
3. **Start the Server**
   ```sh
   node server.js
   ```
   Backend runs at **`http://localhost:5000`**.
